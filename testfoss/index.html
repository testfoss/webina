Webina archived browser demo

This additive fork builds and serves the archived Webina 1.0.5 UI without changing it. The UI uses the repository’s checked-in, prebuilt AutoDock Vina 1.2.3 WebAssembly, JavaScript, and worker under src/Webina/; CI does not recompile Vina.

Launch the built archived Webina UI

Choose Use Example Files to load the stock 1xdn/ATP PDBQT inputs. The server must send COOP and COEP headers for SharedArrayBuffer. Build output and docking output are ephemeral and are not checked in.

Webina’s LICENSE.md is Apache-2.0. Its upstream package.json independently says ISC; this fork records that discrepancy without changing either file.
